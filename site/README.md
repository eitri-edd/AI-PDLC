# AI-SDLC guide

Static site source and publishable files are in `dist/`. No build or package installation is required. Serve this folder with a local static web server to preview the site.

- `dist/index.html`: Introduction, based on the user-provided Chapter 0 and audience brief, with three inline SVG figures and a comparison table.
- `dist/transformation.html`: Organisation transformation: practical changes across people, process, culture and technology, with three inline SVG figures, cited research and a measurable pilot procedure. See `transformation-review.md` for the editorial review and source limitations.
- `dist/concept.html`: Models plus seven development concepts covering intent, specifications, context, harnesses, loops, execution graphs and software factories. Models summarises large language models, domain-specific language models, small language models and System One, with a comparison table, practical example and five annotated research references. The seven development concepts explain their purpose, operation and limits with diagrams, examples and concise application ideas. Learning resources are grouped in a reference list. The harness diagram explains the six components in the supplied reference image. See `concepts-review.md` for source reviews and editorial decisions.
- `dist/product-ideation.html`: Product ideation ("making the right product"): Frame → Test → Decide → Handoff, with six practical steps, early Product/Design/Engineering collaboration, a continuous fictional service-desk example and six accessible inline SVG figures. Agentic UX and advanced theory are optional deep dives. `dist/product-ideation.css` adds reading aids using shared design tokens; `dist/product-ideation.js` reveals linked optional content and expands it for printing. Revised on 28 October 2026; see `product-ideation-review.md` and the earlier `product-pages-review.md` for source context.
- `dist/product-implementation.html`: Product implementation ("making the product right"), based on Chapter 3: readiness package (PRD, UI artefacts, organisational context), PRD to TRD to tasks, the six-stage loop, gates and independent assurance, factory platform, autonomy modes, measures and pilot readiness, with three figures. The final section, "Run the loop with the EDS workflow", maps the strategy to the EDS AI Workflow pages.
- `dist/eds-ai-workflow.html` and five child pages: EDS AI Workflow (Eitri Agentic Dev Workflow), based on the harness documentation in `../harness-workflow/` (cited by title only), with the earlier EDS handbook retained for working principles. Overview (`eds-ai-workflow.html`), PO/BA harness (`eds-po-ba-harness.html`), developer harness (`eds-developer-harness.html`), path to production (`eds-path-to-production.html`), team context (`eds-team-context.html`) and skills catalogue (`eds-skills-catalogue.html`). The sidebar nests the child pages under the overview. See `eds-workflow-review.md` for decisions, source inconsistencies resolved and validation.
- `dist/training.html`: Training, a study guide to the Eitri Agentic Dev Workflow self-paced training. No longer linked from the site; the sidebar's Training entry points to the external self-paced course.
- `dist/styles.css`: Shared styles from `../design.md`.
- `dist/site.js`: Responsive navigation and current-section indication.

Read `../writing.md` and `../design.md` before changes. Reference documents are not included in the public output. Publish only the contents of `dist/`, not the entire workspace. Relative links support hosting below a repository path.

Confirm the content owner, applicable lifecycle version and substantive review date before publishing maintained guidance. Page status metadata is not required and should not be added to page headers or description metadata. Editorial status may be tracked in maintenance records when useful. GitHub Pages publishes `dist/` from `main` through `.github/workflows/pages.yml`; proposed changes can be reviewed in a pull request before merging.

The ideation and implementation pages were reviewed and supplemented with online sources on 28 September 2026. See `product-pages-review.md` for the source mapping, editorial changes and validation, including experiment design, AI evaluation, delivery measures and release recovery.
